# Quant Finance Project

변동성 트레이딩 파이프라인(블랙-숄즈 IV → GARCH 변동성 예측 → 신호 → 델타헤지)을 Streamlit 앱으로 만든 프로젝트입니다.
모든 예측은 **그 시점까지의 데이터로만 학습하는 워크포워드 방식**으로 검증하고, 검증 결과를 화면에 함께 보여줍니다.
분석·검증용 도구이며 주문을 내는 실거래 시스템이 아닙니다 ([범위와 한계](#범위와-한계)).

![tests](https://github.com/Hyeonwoo01/Quant_Finance_Project/actions/workflows/tests.yml/badge.svg)

## 기능

| 탭 | 내용 |
|---|---|
| 주가 예측 범위 | t분포 GARCH 시뮬레이션으로 향후 68%·95% 가격 범위, 손실 위험(VaR·ES, 모델 vs 과거 실제). GARCH 추정이 수렴하지 않으면 기본값으로 대체하고 경고 표시 |
| 방향 예측 | 가격·거시·실적·수급·공시 특징 + 여러 모델을 자동 선택 (기본 확률보다 낫지 않으면 기본 확률 사용), 전략 샤프·최대 낙폭, 가정 바꿔 점검(자동 선택 기간·보유 기준×거래비용·시기·예측 기간 — 가벼운 점검 / 부스팅 포함 점검) |
| 코스피 종목 고르기 | 코스피 대형주 약 200개의 상대 순위 (모멘텀·저변동성·수급·실적·자사주·가치 지표), 생존 편향 완화, 최대 낙폭 |
| 시장 심리 | 옵션 풋/콜·스큐, 컨센서스, DART 공시, 뉴스 감성 (현재 값, 참고용) |
| 변동성 | 실현·조건부·내재 변동성 비교, GARCH 계수와 꼬리 두께(ν) |
| 시장 국면 | 2상태 국면 전환 모델(안정/불안), 워크포워드 국면 확률, '불안 국면엔 현금' 전략 vs 단순 보유 |
| 옵션 가격 & 헤지 손익 | 옵션 가격 수준(IV − GARCH 예측, 매매 추천 아님), 스트래들 델타헤지 몬테카를로, VIX·VXN·RVX를 과거 IV로 쓴 신호 백테스트 (SPY·QQQ·IWM 등, 헤지 델타는 매일의 지수 값으로 다시 계산), GARCH+IV 결합 예측 비교, '매도만' 규칙을 앞 기간에서 고르고 뒤 기간에서 검증, 현실성 점검(VIX−ATM IV 차이·옵션 체결 비용·진입일), '매도만' 결과가 (차이 × 진입일) 20개 조합에서 유지되는지 |
| 예측 정확도 검증 | GARCH vs 단순 예측의 과거 오차, 범위 적중률, VaR 초과 비율, 하루 VaR 예외 검정(Kupiec·Christoffersen) |

## 실행

Windows: `run.bat` 더블클릭 (처음 실행 시 가상환경을 만들고 패키지를 설치합니다).
`requirements.txt`는 테스트를 통과한 버전으로 고정돼 있어 **Python 3.12 이상**이 필요합니다 (3.13에서 확인).

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m streamlit run app.py
```

### API 키 (선택)

한국 종목의 DART 공시·재무제표와 한국은행 금리를 쓰려면 `api_keys.env.example`을 `api_keys.env`로 복사해 키를 넣으세요.
키는 [OpenDART](https://opendart.fss.or.kr)와 [한국은행 ECOS](https://ecos.bok.or.kr/api/)에서 무료로 발급됩니다.
`api_keys.env`는 `.gitignore`에 들어 있어 저장소에 올라가지 않습니다.

### 코스피 종목 고르기 데이터

앱의 코스피 종목 고르기 탭에서 **데이터 받기**를 누르거나 `python universe.py update`를 실행하세요 (처음 20~40분).

### 테스트

`python tests.py` (1분 안팎). GitHub에 올릴 때마다 GitHub Actions가 Python 3.12·3.13에서 같은 테스트를 자동으로 돌립니다.

## 백테스트 가정

| 항목 | 가정 |
|---|---|
| 체결 시점 | t일 종가까지 보고 판단 → **다음 거래일 종가에 체결** (기본). 사이드바 '백테스트 체결 시점'에서 '신호 낸 날 종가(낙관적)'로 바꿔 비교할 수 있음. 방향 예측·시장 국면·코스피 종목 고르기·변동성 신호 백테스트에 모두 적용 |
| 거래비용 | 사이드바 '거래비용(bp)'을 포지션이 바뀔 때마다 차감 (변동성 백테스트에선 주식 헤지 비용). 옵션은 진입할 때 '옵션 체결 비용(스트래들 가격 대비 %)'을 한 번 차감 |
| 과거 IV | 과거 옵션 가격이 없어 VIX(SPY)·VXN(QQQ)·RVX(IWM) − 차이(%p)를 ATM IV로 씀. 신호는 판단일, 옵션 가격은 체결일의 값을 쓰고, 헤지 델타는 매일 그날의 값으로 다시 계산 |
| 미래 정보 차단 | 모든 모델은 판단 시점까지의 데이터로만 학습·선택. `tests.py`가 미래 데이터를 바꿔도 과거 예측이 그대로인지 확인 |
| 겹치는 예측 기간 | h일 예측을 매일 하면 정답이 h일씩 겹쳐 표본이 과대평가됨 → 방향 예측의 z는 Newey-West(HAC) 표준오차(시차 h−1)로 계산 |
| VaR 검증 | 하루 VaR(95%·99%)를 직전 750일로 21일마다 다시 추정해 최근 약 500일에 적용. Kupiec(예외 비율이 목표와 같은가)·Christoffersen(예외가 몰려 나오지 않는가) 검정, 종합 p값 > 0.05면 통과 |
| GARCH 추정 | 시작값 3개로 최적화하고, 모두 실패하면 α=0.05·β=0.90·장기 분산=표본 분산으로 대체하고 화면에 경고. α+β가 1에 아주 가깝거나 꼬리 두께 ν가 경계값이면 함께 경고 |

## 검증 결과 메모

아래 숫자는 각 날짜의 코드로 계산한 것입니다. 2026-10-22부터 기본 가정이 '다음 날 종가 체결', '매일의 IV로 헤지',
'Newey-West z'로 바뀌어 지금 앱에서 같은 설정으로 돌리면 숫자가 조금 다를 수 있습니다 (결론이 바뀌는지는 앱에서 다시 확인).

### 변동성 매매 (2026-10-21 실행)

SPY, 과거 IV = VIX − 차이, 2018-10 ~ 2026-08에 한 달(21거래일) 간격 95번 진입. 매번 그때까지의 데이터로만 GARCH 예측,
ATM 스트래들을 매일 델타헤지해 만기 정산. 설정: VRP 2%p, 관망 구간 ±2%p, 주식 헤지 비용 1bp, 옵션 체결 비용 1%.
당시 가정: 신호를 낸 날 종가에 진입, 헤지 델타는 진입 시 IV 하나로 계산.

| 전략 | 결과 | 결론 |
|---|---|---|
| GARCH 양방향 신호 (IV − 예측으로 사고팔기) | 차이 2%p에서 샤프 −0.15 (t −0.4). 차이 0~3%p, 진입일 5가지 어디서도 우위 없음 (샤프 −0.31 ~ 0.44) | ❌ 우위 없음 |
| 매도만 + GARCH 필터 (IV > 예측일 때만 매도) | 앞/뒤 기간 한 번 나눈 검증(차이 2%p)에선 뒤 기간 샤프 1.29 vs 항상 매도 0.71로 통과. 그러나 (차이 4 × 진입일 5) 20개 조합 중 **8개**에서만 항상 매도보다 나았고, 조합마다 규칙을 다시 고르면 5개 | ❌ 운 좋은 조합이었을 가능성 큼 |
| 항상 매도 (변동성 위험 프리미엄) | 차이 0 / 1 / 2 / 3%p에서 거래당 +0.75 / +0.53 / +0.30 / +0.08% (주가 대비), t 6.2 / 4.5 / 2.6 / 0.7. 진입일에 따라 샤프 0.63 ~ 1.26 | △ 이익의 크기가 VIX와 실제 ATM IV의 차이에 크게 좌우됨 (3%p면 거의 0) |
| 변동성 예측 (21일 실제 변동성) | GARCH RMSE 7.5% vs 'VIX − 과거 평균 VRP'·'GARCH+VIX 결합' 6.5% (71번). GARCH 대비 개선 t 1.4 ~ 1.5 | △ VIX를 쓰면 나아 보이나 우연과 구분 안 됨 |

- **결론:** 검증된 변동성 매매 전략은 없습니다. 그래서 앱은 IV − GARCH 예측을 매매 신호가 아니라 **옵션 가격 수준(정보)** 으로만 보여줍니다.
  계산과 백테스트는 남겨 두어 다른 종목(QQQ·IWM)·기간에서 다시 확인할 수 있습니다.
- **남은 불확실성:** VIX와 실제 ATM IV의 차이. 실제 옵션 가격 기록(유료 데이터)이 있어야 해소됩니다.
- **교훈:** 앞/뒤 기간을 한 번 나눈 검증은 통과했지만 가정(IV 차이·진입일)을 바꾸자 무너졌습니다.
  결론은 늘 '가정을 바꿔도 유지될까?' 점검까지 보고 내립니다.

### 방향 예측 (2026-10-22 실행)

SPY, 가격·거시·옵션 심리 특징, 워크포워드 자동 선택. 당시 가정: 신호를 낸 날 종가에 체결, z는 '표본 수 ÷ 예측 기간'으로 보정.

| 점검 | 결과 | 결론 |
|---|---|---|
| 21일 방향, 가정 바꿔 점검 (자동 선택 기간 1·2·3·5년 4개 + 시기 3구간 = 7개) | 7개 중 **0개** 통과. 자동 선택이 거의 100% '기본 확률(과거 상승 비율 약 69%)'을 골라, 전략이 내내 보유 = 단순 보유와 같음 (샤프 0.73 vs 0.73) | ❌ 예측력 없음 |
| 예측 기간 5·10·21·42·63일, 부스팅까지 포함 (1년마다 재학습) | 부스팅·앙상블이 골라진 비율 **모든 기간 0%**. 5~42일은 단순 보유와 같고, 63일은 가끔 로지스틱이 골라졌다가 손해 (−2.4%, 샤프 0.64 vs 0.70) | ❌ 기간을 늘려도, 모델을 무겁게 해도 안 됨 |

- **결론:** SPY의 5~63일 방향은 이 특징·모델들로 예측되지 않았습니다. 앱은 설계대로 근거 없는 신호를 내지 않고 '과거 상승 비율'로 물러났습니다.
- **63일의 손해:** 63일 예측은 서로 독립적인 표본이 30개 안팎이라, 과거에 잘 맞은 것처럼 보인 모델이 우연이었을 가능성이 큽니다.

## 범위와 한계

- **실거래 시스템이 아닙니다.** 주문 실행(OMS), 브로커 연동, 킬 스위치, 포지션·손실 한도, 실시간 체결 관리 같은 기능이 없습니다.
  예측과 과거 검증을 보여주는 분석·연구 도구이며, 백테스트 손익은 위 가정 아래의 계산값입니다.
- **체결:** 종가에 원하는 수량이 체결된다고 가정합니다. 호가 공백·시장 충격·장중 가격 변동은 반영하지 않습니다.
- **옵션 데이터:** 과거 옵션 체인이 없어 변동성 지수 − 차이로 ATM IV를 대신합니다. 실제 IV와의 차이, 옵션 체결 비용은 가정값입니다.
- **코스피 종목 범위:** 과거 시점마다 그때의 거래대금 상위 200개를 써서 '지금 큰 종목' 편향은 없앴지만,
  그 사이 상장폐지된 종목은 무료 데이터로 주가를 구할 수 없어 빠져 있습니다 (생존 편향이 일부 남음).
- **데이터 출처:** 무료 데이터 소스(Yahoo Finance, 네이버 증권 비공식 API 등)는 예고 없이 바뀌거나 지연·누락될 수 있습니다.
- **통계:** 겹치는 예측 기간은 Newey-West로 보정하지만, 여러 가정을 시험할수록 우연히 좋은 결과가 나올 가능성(다중 비교)은 남습니다.
  그래서 결론은 한 조합이 아니라 '가정을 바꿔도 유지되는지'로 판단합니다.

교육·연구용입니다. 투자 조언이 아니며, 과거 검증 결과가 미래 성과를 보장하지 않습니다.
